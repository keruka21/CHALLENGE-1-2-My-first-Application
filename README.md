# Flora and Fauna of Biscay

**Flora and Fauna of Biscay** is an academic front-end web development project created as part of the first-year coursework for the Higher Vocational Education and Training programme in Multiplatform Application Development (DAM), specifically for the BDA and LMS subjects.

The project consists of a website prototype dedicated to showcasing the biodiversity of Biscay (Bizkaia), in the Basque Country.
Its main purpose is to provide an accessible and engaging way to explore the region's native flora and fauna through a collection of species profiles, habitats, geographical regions and wildlife sightings.

The website features an interactive species catalogue, dedicated species information pages, habitat and regional sections, and a gallery of wildlife observations.
It also incorporates multilingual content in English and Basque, with a responsive interface designed to provide a consistent user experience across different devices.

This project focuses primarily on front-end development, including HTML, CSS, JavaScript and Bootstrap(framework).
It is a functional interface prototype developed for educational purposes and does not represent a complete production-ready platform.
